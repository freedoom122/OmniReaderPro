### License notes for distribution

- **PySide6 (LGPL-3.0):** Dynamic linking satisfies the LGPL; the app does
  not statically link Qt. Users may replace the Qt libraries. No source
  disclosure obligation for the application itself.
- **PyMuPDF & EbookLib (AGPL-3.0):** AGPL obligations apply to
  *distributing* these libraries' code and to network-interacting
  modifications of them. They are used unmodified as libraries. **If you
  distribute Veyrion Workspace commercially, review the AGPL requirements
  (offer of source for the library, license notice, and — if the
  application is made available to users over a network — the corresponding
  source offer for AGPL-covered code).** If AGPL is unacceptable for your
  use, alternatives exist (e.g., MuPDF's commercial license) — see
  DECISIONS.md.
- **PyInstaller (GPL-2.0+ with bootloader exception):** The PyInstaller
  *bootloader* is distributed under the GPL with a special exception that
  permits using it to package applications under any license. The bundled
  Python runtime and standard library are under the Python License (PSF).
  Bundling via PyInstaller does not make the application GPL.
- **odfpy:** dual-licensed Apache-2.0 / GPL-2.0; we use it under the
  Apache-2.0 terms.
- **Tesseract OCR engine:** NOT bundled. When installed separately by the
  user, Tesseract is Apache-2.0.
- **unrar:** NOT bundled. The `rarfile` library merely interfaces with an
  external `unrar`/`unar` if the user installs one; the RAR codec itself is
  proprietary, which is why it is never bundled.

## Bundled data

- **Dictionary source:** Veyrion Workspace ships a wordnet-style lexical data
  source (public-domain word lists and Princeton WordNet data under its
  permissive license). It is used only for offline dictionary lookup.

Full texts of MIT, BSD, Apache-2.0, LGPL-3.0, AGPL-3.0, MPL-2.0, ISC, and
HPND licenses are distributed inside the installed package under
`resources/licenses/` and in the `licenses/` directory of this repository

present). If a license text is missing from your build, it can be obtained
from the package's canonical distribution (PyPI) or from the links in the
dependency metadata.
